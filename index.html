Cycle

Indoor cycling training for GNOME — smart trainer control, structured workouts, session recording.

Install

flatpak remote-add --if-not-exists cycle https://rorynuijens.github.io/Cycle/cycle.flatpakrepo
flatpak install cycle io.github.rorynuijens.Cycle

Updates then arrive with flatpak update.

Latest version: 0.7.3 — source and releases
