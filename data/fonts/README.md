# Fonts

`Fredoka.ttf` — Fredoka, a variable font (Light to Bold) by The Fredoka
Project Authors, from https://github.com/google/fonts/tree/main/ofl/fredoka.
Licensed under the SIL Open Font License 1.1 (`OFL.txt`), which allows
bundling it with the app.

Used only by the fullscreen ride HUD (`src/ui/widgets/ride_hud.rs`), which is
drawn inside the 3D view in the world's own cartoon style. The app's own UI
keeps the system font.
